# Internationalization

- Every user-visible string goes through `AppLocalizations` (ARB files + `l10n.yaml`, `flutter_localizations`). No literal UI strings, except in tests and debug tools.
- ARB keys are `lowerCamelCase` and describe meaning (`feedEmptyTitle`), with `@key` descriptions for translators.
- Plurals and genders use ICU syntax in ARB, never string concatenation.
- Dates, numbers and currency use `intl` formatters with the active locale.
- Layouts must survive 30% longer text and right-to-left (`Directionality`, `EdgeInsetsDirectional`).
- In a builder-owned UI package, the builder may own the ARB files: add keys through it, or follow `ownership.md`.
