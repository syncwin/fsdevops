# Precedence

1. **Official documentation**: docs.flutter.dev, dart.dev (Effective Dart, lints), api.flutter.dev, pub.dev package docs for the pinned version, platform docs (Microsoft for Windows/MSIX, Android developers, Apple developer).
2. **Project rules**: the repo's `analysis_options.yaml`, `.claude/ownership.md`, CONTRIBUTING, and an approved PRD or change brief.
3. **Role skills** in this plugin.
4. **House rules** in build skills.

House rules may be stricter than a higher level, never looser. When two sources conflict, follow the higher one and say which rule you followed. When official docs are silent, say "house rule" so the user knows it is an opinion.
